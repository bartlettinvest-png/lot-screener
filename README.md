# Lot Screener

A one-page buildability check for Upper Cumberland, Tennessee land. Paste an address, parcel ID, map point or wholesaler email, or search for sites. It screens a lot for a house or a multi-building flex-space site: size, water and sewer, flood, soils, lidar slope and pads, dirt work, zoning, corridor access and land cost against build cost. All data comes from public state, FEMA, USDA and USGS map services.
